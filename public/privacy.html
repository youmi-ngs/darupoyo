プライバシーポリシー

制定日：2026年11月9日

だるぽよ開発チーム（以下「運営」）は、家事記録アプリ「だるぽよ」（以下「本サービス」）で、あなたの情報を次のとおり扱います。

1. 集める情報

ログイン情報Google アカウントでのログインに Firebase Authentication を使います。本サービスのデータベースに保存するのは、アカウントを識別するユーザーIDです。メールアドレスなどのアカウント情報は Firebase Authentication が管理します。
入力した内容表示名、ハウスの名前、記録や写真に添える「ひとこと」、コメント、リアクション、設定（テーマカラー、ギャルの選択、通知など）
写真ごはんの写真、ゴミ出しのポーズの写真（背景を切り抜いたもの）、「うちらのなう」の写真、「だるぽよ」に添えた写真、プロフィール写真
音声ごはんの「いただきます」「ごちそうさま」の録音（マイクをオンにしている間だけ、最大10秒）
記録の情報家事の種類、記録した日時、方法、ポーズの体の位置（骨格の座標）、リズム・音の結果など
通知の情報通知をオンにした端末に届けるためのトークン

ポーズや洗濯のリズムの判定に使うカメラの映像と、ドライヤーの音の判定に使うマイクの音は、端末の中だけで処理し、保存も送信もしません（ゴミ出しの写真は、撮った1枚だけを保存します）。端末の位置情報は使いません。

2. 使いみち

  • 家事の記録、けーじばん、うちらのなう、だるぽよなど、本サービスの機能を動かすため
  • ハウスの住人どうしで記録・写真・コメントを見られるようにするため
  • ギャルのひとことや通知の文章をつくるため
  • 「いただきます」と言えているかを確かめるため
  • 不正な利用を防ぎ、不具合を直すため

3. AI（Google の Gemini）に送る情報

本サービスは、Google Cloud の Vertex AI（Gemini）を使っています。次の情報を Gemini に送り、結果だけを本サービスで使います。

  • 「いただきます」の録音：言えているかの確認のため
  • 「うちらのなう」の写真とひとこと：ギャルのひとことをつくるため
  • 「だるぽよ」の家事の種類・ひとこと・写真（あれば）：ギャルのひとことをつくるため
  • 家事の記録の内容（家事の種類・ひとことなど）：ギャルのひとことや通知の文章をつくるため。家事の写真は送りません

Google による扱いは、Google Cloud の規約とプライバシー通知にしたがいます。

4. 使っている外部のサービス

  • Google Cloud・Firebase（ログイン、データベース、写真・音声の保存、サーバー、ホスティング、通知の配信）
  • Google Cloud Vertex AI（Gemini）
  • Google Maps Platform の Weather API（部屋の窓の天気。東京の決まった地点の天気を取得するだけで、あなたの位置は送りません）

5. だれに見えるか

  • 記録・写真・音声・コメントは、同じハウスの住人に見えます。
  • 投稿するときの「共有範囲」で、あなたが住んでいるほかのハウスも選ぶと、そのハウスにも同じ投稿（写真・音声を含む）が置かれ、そこの住人にも見えます。はじめは「いまのハウス」だけです。編集・削除は選んだすべてのハウスに反映されます。
  • 運営は、法令にもとづく場合を除き、あなたの情報を第三者に売ったり渡したりしません。

6. 端末に保存するもの

音のオン・オフ、遊び方を見たかどうか、ギャルの選択などを、ブラウザの保存領域（localStorage）に保存します。アクセス解析や広告のための Cookie は使っていません。

7. 消したいとき

  • マイページの「アカウントを削除」で、あなたの記録・写真・音声・コメント・リアクション・設定を削除します。
  • 「ハウスから退去」で、そのハウスでのあなたの記録・写真・音声などを削除します。
  • 自分のコメントはいつでも消せます。

削除したデータは元に戻せません。バックアップなどから完全に消えるまで、少し時間がかかることがあります。

8. 年齢

本サービスは 18歳以上 の方を対象にしています。本サービスが使っている Google Cloud の生成AIサービスの年齢制限に対応するためです。

9. 安全のために

通信は暗号化（HTTPS）しています。データはログインした本人とハウスの住人だけが使えるようにしています。ただし、インターネット上で完全な安全を約束することはできません。

10. このポリシーの変更

内容を変えるときは、このページで知らせます。大きな変更は、アプリの中でも知らせます。

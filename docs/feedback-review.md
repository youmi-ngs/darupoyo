## F10 / #206：ドライヤーは実機確認待ち

`src/audio.js` の現状はYAMNetの上位5候補中、hair dryerのスコア0.2以上を累積10秒。マイクのechoCancellation / noiseSuppressionは既にfalse。失敗時の録音・端末情報がないため、検出不良を再現したとは言えない。判定値は変更していない。

他の確認後、失敗する端末・ブラウザ・ドライヤーとの距離・周囲の音・進捗が0のままか途中まで増えるかをユーザーに確認する。必要なら本人の同意のもとで録音を用意して、正常音・別の生活音との誤検出も比較する。原音を無断収集する機能は追加しない。

## F13 / #208：技術説明との照合

- Firebase UIDはログインのたびの新しいIDではないため、privacyの説明を「アカウントを識別するユーザーID」に修正。
- 保存可能な音声にはAPI上「ごちそうさま」の記録もある（domain.finish_meal）。privacyの音声一覧へ追記。Geminiへ送る説明は「いただきます」のまま維持。
- Geminiへの送信は、いただきますの録音（itadakimasu.py）、なうの写真・本文（main.py / services.py）、家事・通知の文脈。端末内のポーズ／洗濯判定映像・ドライヤー音とは区別されている。
- 年齢制限の参照先を [Google Cloud Service Specific Terms](https://cloud.google.com/terms/service-terms) に明示。確認時点の生成AIサービスの年齢制限に合わせ、既存の18歳以上方針を維持。
- Weather APIは固定地点（東京）。端末位置を送信しない実装と説明が一致。
- 規約・privacyページの存在だけで法的な適合性の全確認が完了したとは扱わない。運営者・問い合わせ先・実際の運用条件はチームの最終確認対象。

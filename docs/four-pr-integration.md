# 4担当PRの統合（2026-11-07）

PR #111（写真・共有）、#112（撮影・ゲーム）、#113（日々の記録・遊び）、#114（部屋の見た目）を、各ブランチの履歴を残して統合します。

- メニューを復活させ、項目は「設定」「遊び方」「招待リンク」の3つ。掲示板は横スワイプ、うちらのなうは玄関の入口を維持します。
- 招待画面では参加用URLと招待コードをそれぞれコピーできます。リンクを開くと招待参加画面になります。
- `main.py` のアップロード種別競合は `avatar` と `darupoyo` の両方を残して解決しました。
- 玄関は新しい家具SVG・ドア・床とタイムラインを共存させています。
- 他ハウスの履歴APIは200件ごとの `next_cursor` / `before` に対応。本人の古い記録が他の住人の投稿で押し出されないように取得します。写真・音声の取得にも共有設定と公開済みの本人投稿への参照を要求し、未投稿のアップロードは共有しません。
- プロフィール写真は差し替え時に旧写真を使用終了扱いにしてから削除し、並行リクエストが削除対象を再選択できないようにしました。
- #113 の記録形式・削除対象・家具との接続は `daily-tasks-integration.md` に記載しています。だるぽよ記録は現在のハウスの掲示板に表示し、別ハウスへ共有しません。
- 1日の境界は引き続きJST朝4時です。
